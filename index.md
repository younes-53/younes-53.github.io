## 📖 How to Use

1. **Integrate into Your Project:** Add the necessary JavaScript file to your web project. Place it in your HTML file before the closing `</body>` tag.

2. **Add Lazy Loading to Your Images:** Add a special class or attribute (like `data-src`) to the images that you want to lazy load. This tells the script which images to delay loading.

3. **Test Your Setup:** Open your website in a browser to see if images load as you scroll. Adjust any settings based on your observations.
